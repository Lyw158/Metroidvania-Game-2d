# 设计决策记录（ADR）

> 状态: 持续更新 | 最近更新: 2026-10-06

记录重要设计决策及其理由，供人与 agent 追溯「为什么这样做」。
推翻旧决策时不删除原记录，而是新增一条并标注「已推翻」。

## 决策模板

```markdown
### DX 决策标题
- 日期: YYYY-MM-DD
- 状态: 已确定 / 已推翻
- 背景: 为什么需要做这个决策
- 选项: 考虑过的方案
- 结论: 最终选择
- 理由: 为什么选它
- 影响: 对后续设计/工程的约束
```

## 已确定决策

### D1 题材基底：奥日式明亮画风

- 日期: 2026-10-06
- 状态: 已确定
- 背景: 游戏受《空洞骑士》与《奥日》启发，需先定基调。空洞骑士式暗黑压抑路线被排除。
- 选项: 地下王国黑暗奇幻 / 自然生机奇境（奥日式）/ 双层世界混合 / 废墟科技文明
- 结论: 奥日式明亮画风为基底；具体世界观主题仍待定（候选见 [design/world.md](design/world.md)）
- 理由: 用户偏好明亮画面，且与空洞骑士形成差异化
- 影响: 美术、音效、剧情均以明亮基调为约束；区域可有个别风格变化，但整体不压抑

### D2 玩法核心：平台跳跃 + 战斗

- 日期: 2026-10-06
- 状态: 已确定
- 背景: 确定游戏的主要玩法组成。
- 选项: 纯平台跳跃 / 纯战斗 / 平台跳跃 + 战斗
- 结论: 平台跳跃为主，战斗为重要组成
- 理由: 用户明确「主要玩法暂定平台跳跃和战斗」
- 影响: 战斗具体形态（近战/远程/混合）仍待定；与 roadmap M5 战斗里程碑衔接

### D3 文档结构：总纲 + 专题文件

- 日期: 2026-10-06
- 状态: 已确定
- 背景: 需要一种文档组织方式，保证后续方案不断扩充时人与 agent 都能快速定位内容。
- 选项: 总纲 + 专题文件 / 单一 GDD 大文件 / 子目录分主题
- 结论: gdd.md 总纲（唯一入口）+ design/ 专题文件 + decisions.md 决策记录
- 理由: 单一入口降低阅读成本；专题拆分避免单文件膨胀；决策留痕支持回溯
- 影响: 新增专题文件必须在 gdd.md 文档导航表登记

### D4 占位素材策略：免费素材占位

- 日期: 2026-10-06
- 状态: 已确定
- 背景: 验证期需要一批占位资源接入系统，同时保证正式素材替换零成本。
- 选项: 全部色块占位 / 全部免费素材 / 用户自制占位素材
- 结论: 占位素材一律用免费可商用素材；正式素材由用户自制
- 理由: 用户明确「先用免费素材当占位符」；免费素材比色块更接近最终表现，便于评估手感与氛围
- 影响: roadmap 第四章新增资源清单（必需/次要）；所有素材替换零代码改动；资源按必需优先推进，次要资源延后
