# 核心体验设计

> 状态: 草案 | 最近更新: 2026-10-06
> 本文档定义「玩起来是什么感觉」的设计意图；工程落地计划见 [roadmap.md](../roadmap.md)（M1 控制器、M5 战斗）。

## 一、平台跳跃

**手感目标**：

- **跟手**：输入到动作的延迟不可感知；起步、转向、跳跃响应即时。
- **流畅**：动作之间可连续衔接（跳跃→蹬墙→冲刺），不存在"卡手"的过渡。
- **失误可归因**：玩家失败时应能立刻明白「我哪一步做错了」，而非「手感飘」。

**参考系**：《奥日》的流动感——跳跃有高度弹性、空中操作余地大、移动本身就是乐趣。

**与 roadmap 的关系**：M1 是本节的工程落地（加速/减速、可变跳跃高度、Coyote Time、Jump Buffer 等具体手段）；本节只定「目标」，M1 定「参数」。

## 二、战斗定位

**暂定原则：战斗是移动的延伸**——战斗不应打断探索的流动感，攻击动作应与移动能力衔接（如空中攻击、移动中出招）。

**开放问题**：

1. 攻击形态：近战（如挥砍）/ 远程（如投射物）/ 混合？
2. 战斗权重：遭遇战式（少而精）还是高频清版式？
3. 是否引入「动作取消」机制（攻击后摇可被闪避/跳跃取消）？

## 三、探索循环

核心循环（与 roadmap M3 的验证目标一致，这里是设计意图）：

```
探索 → 遇到能力门（过不去）→ 获得新能力 → 回溯通过 → 新区域
```

**设计意图**：

- 能力门不是硬锁，而是「看得见却够不着」的软性提示——玩家先记住位置，获得能力后自然想起。
- 追求「啊哈时刻」：拿到能力的一瞬间，之前所有过不去的地方在脑中同时点亮。
- 新能力同时服务于移动与战斗（如冲刺既是位移也是攻击手段），让解锁有双重价值。

## 四、节奏目标

**暂定参考值（可调）**：

- 平台跳跃约占总体验 60%，战斗约 30%，其余（解谜、剧情）约 10%。
- 战斗频率：以「少量而有个性」的遭遇战为主，避免刷怪感。
- 关卡节奏：紧张平台段落与探索段落交替，不留「赶路纯跑图」的长距离。
